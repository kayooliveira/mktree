## [1.1.0] - 2025-12-26

- Only creates folders/files from valid tree diagrams, ignoring comments and non-structure text
- CodeLens menu now appears at the top of valid tree blocks
- Visual decorator highlights only real tree blocks with a subtle style
- Extension works with unsaved (untitled) files using workspace root
- All messages use localization, no hardcoded strings
- Source code cleaned up (no comments)
